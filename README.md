# 🐉 Toca do Dragão

Projeto de programação desenvolvido em Python.

## 📌 Sobre o projeto

A Toca do Dragão é um sistema de loja desenvolvido para praticar
conceitos fundamentais de programação em Python.

O projeto possui sistema de login, catálogo de produtos,
controle de estoque, saldo de moedas, carrinho de compras
e finalização da compra.

## 🛠️ Tecnologias

- Python
- Git
- GitHub

## 📚 Conceitos praticados

- Variáveis
- Listas
- Estruturas condicionais
- Estruturas de repetição
- Funções
- Entrada e saída de dados
- Controle de estoque
- Lógica de programação
